# Data Science Projects

This repository collects my data science and analytics projects.  
Each subfolder contains a self‑contained project with code, data (when possible), and a short description.

## What you will find here

The projects come from different sources and difficulty levels:

- **Learning platforms** – real-world projects from courses (e.g. DataCamp).
- **Public datasets** – small analyses and models based on data from Kaggle or other open sources.
- **Personal projects** – my own case studies using data that I collected or generated myself.

Most projects are focused on:

- exploratory data analysis (EDA),
- basic statistics for data science,
- classic machine learning (regression and classification),
- data visualization in Python (pandas, Matplotlib, seaborn).

## Structure

Each project lives in its own folder, for example:

- `netflix-movies-1990s-eda/`
- `...`

Inside a project folder you can usually find:

- a Jupyter notebook (`.ipynb`) with the analysis,
- a `data/` folder with the main dataset (if it can be shared),
- an `images/` folder with plots or screenshots (optional),
- a project‑specific `README.md` describing the goal and main results.

## Technologies

Most projects use:

- **Python** – main programming language,
- **pandas** – data manipulation and cleaning,
- **NumPy** – numerical operations,
- **Matplotlib / seaborn** – visualizations,
- **scikit‑learn** – classic machine learning models (in some projects).

Over time this folder will grow as I complete more learning projects and personal case studies.
